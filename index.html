Notes

  • No chrome or structural component has a Supernova documentation page or a Storybook story. The only doc coverage for this whole category is one narrative page, Desktop/Patterns/Browser anatomy/Overview.
  • Checkbox and Radio each ship both a modern moz-* version and a classic version at the same time, marked "moz-* + classic" rather than picking one.
  • A row with no real Firefox equivalent (Chip, Details) gets no implementation badge at all, not a "pattern" badge of its own: it isn't an implementation kind, just the absence of one. See its file citation for what actually exists instead (a Figma-only pattern, a distinct real feature that only looks similar, native HTML doing the job, etc.). This is different from the "pattern" badge (red), which means the real thing exists as page wiring with no dedicated class.
  • Figma has some internal duplication for chrome entries (Sidebar, Infobar and Info bar, Bookmarks toolbar and Bookmarks Toolbar, and a few more each show up as two near-identical nodes), most likely stale-versus-current branches rather than distinct concepts.
  • tagName is optional, not universal: most "classic" entries do have a real customElements.define tag (panel, dialog, tab-group), but "pattern" entries never do, and some real implementations (Spotlight, Callout) are plain classes or React, not custom elements at all.
  • A grey "n/a" in the Storybook column is a different claim than a red cross: it means the real implementation isn't a reusable widget class at all (a plain module like Spotlight, a React render method like Stepper, or page wiring with no class like Toolbox), so a story was never going to exist regardless of effort. A red cross means a real widget class exists and simply hasn't been storied yet, a genuine closeable gap (popup-notification, for example).
  • Rows with no Figma node or Storybook story of their own (Panel Item, Panel Separator, Page Nav Item and Separator, Segment, Icon Button, Split Button, Visual Picker Item) are listed indented under the parent whose Figma node or Storybook story actually covers them, marked "in: [parent name]".
